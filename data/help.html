Register-Beschreibung (pro Segment)

OffsetNameWertebereichR/W
+0Rot (R)0–255R/W
+1Grün (G)0–255R/W
+2Blau (B)0–255R/W
+3Helligkeit (Bri)0–255R/W
+4Effekt (Fx)0=Aus, 1=Static, 2=Flash 4Hz, 3=Flash 0.5Hz, 4=Pulse 2Hz, 5=Pulse 0.33Hz, 6=Strobe 20Hz, 7=Pulse 1Hz, 8=ChaseR/W
+5Aktiviert (En)0 = AUS, 1 = EINR/W

Beispiel: Segment 0 auf Rot static

FC16  Addr=10  Count=6  Data: 255, 0, 0, 200, 1, 1
→ R=255, G=0, B=0, Bri=200, Fx=Static, En=1

Beispiel: Alle LEDs aus

FC06  Addr=0  Value=0   (GlobalEnable = 0)

Kanal-Mapping

Jede Pixelgruppe belegt 4 DMX-Kanäle: R, G, B, Master-Dimmer. Die finale Farbe = RGB × (Dimmer ÷ 255). Gruppen-Größe = Anzahl LEDs pro Gruppe (konfigurierbar).

Kanal-Belegung pro Gruppe

OffsetFunktionWertebereich
+0Rot (R)0–255
+1Grün (G)0–255
+2Blau (B)0–255
+3Master-Dimmer0 = aus, 255 = volle Helligkeit

Beispiel: 50 LEDs, Gruppen-Größe = 3

GruppeDMX-KanäleLEDs
01–4 (R,G,B,Dim)0–2
15–8 (R,G,B,Dim)3–5
29–12 (R,G,B,Dim)6–8
………
1561–64 (R,G,B,Dim)45–47

Konfiguration im Steuer-Programm

  • Universe: wie in LEDCon konfiguriert (Standard: 0)
  • Start-Kanal: 1 (Art-Net zählt ab 1)
  • Anzahl Kanäle: Gruppen × 3
  • Patch-Typ: RGB oder Generic

OTA Firmware-Update

Neue Firmware (.bin) direkt über den Browser hochladen. Das Board startet nach dem Update automatisch neu.

Hinweise

  • Firmware-Datei: firmware.bin aus dem PlatformIO-Build-Ordner
  • Pfad: .pio/build/ledcon_hw/firmware.bin
  • Während des Updates keine Verbindung trennen
  • Das Board neustartet automatisch nach erfolgreichem Update
